🚚 Insert Tuyến Đường Hôm Nay

📌 Hướng dẫn:
  1. Copy đoạn SQL bên dưới
  2. Mở SQL Server Management Studio hoặc Azure Data Studio
  3. Kết nối vào database LogisticsDB
  4. Paste và chạy SQL script
  5. Refresh trang driver-routes.html để xem dữ liệu

📝 SQL Script:

-- Insert sample route for today DECLARE @Today DATE = CAST(GETDATE() AS DATE); DECLARE @RouteId BIGINT; -- Check if route exists for today IF NOT EXISTS (SELECT 1 FROM TuyenDuong WHERE CAST(NgayGiaoHang AS DATE) = @Today AND IdTaiXe IN (1, 3)) BEGIN PRINT 'Creating new route for today...'; -- Insert today's route for driver 1 INSERT INTO TuyenDuong (MaTuyen, IdTaiXe, NgayGiaoHang, TrangThai, TongSoDon, SoDonHoanThanh) VALUES ('TD-Q1-' + FORMAT(@Today, 'ddMMyy'), 1, @Today, 'DANG_GIAO', 4, 2); SET @RouteId = SCOPE_IDENTITY(); PRINT 'Created route with ID: ' + CAST(@RouteId AS VARCHAR); -- Insert delivery points for the route -- Point 1: Already delivered INSERT INTO DiemGiaoHang (IdTuyenDuong, IdDonVanChuyen, ThuTuDung, ThoiGianDuKien, ThoiGianThucTe, TrangThai) VALUES (@RouteId, 1, 1, '08:30:00', '08:45:00', N'DA_DEN'); -- Point 2: Already delivered INSERT INTO DiemGiaoHang (IdTuyenDuong, IdDonVanChuyen, ThuTuDung, ThoiGianDuKien, ThoiGianThucTe, TrangThai) VALUES (@RouteId, 3, 2, '09:15:00', '09:10:00', N'DA_DEN'); -- Point 3: Current delivery (waiting) INSERT INTO DiemGiaoHang (IdTuyenDuong, IdDonVanChuyen, ThuTuDung, ThoiGianDuKien, ThoiGianThucTe, TrangThai) VALUES (@RouteId, 6, 3, '10:00:00', NULL, N'CHO_XU_LY'); -- Point 4: Next delivery (waiting) INSERT INTO DiemGiaoHang (IdTuyenDuong, IdDonVanChuyen, ThuTuDung, ThoiGianDuKien, ThoiGianThucTe, TrangThai) VALUES (@RouteId, 2, 4, '10:45:00', NULL, N'CHO_XU_LY'); PRINT '✅ Successfully inserted route and delivery points!'; END ELSE BEGIN PRINT '⚠️ Route for today already exists! Skipping...'; END -- Display results PRINT ''; PRINT '📊 Current Routes for Today:'; SELECT td.Id, td.MaTuyen, td.IdTaiXe, td.NgayGiaoHang, td.TrangThai, td.TongSoDon, td.SoDonHoanThanh FROM TuyenDuong td WHERE CAST(td.NgayGiaoHang AS DATE) = @Today; PRINT ''; PRINT '📍 Delivery Points:'; SELECT dg.Id, dg.IdTuyenDuong, dg.IdDonVanChuyen, dvc.MaVanDon, dg.ThuTuDung, dg.ThoiGianDuKien, dg.ThoiGianThucTe, dg.TrangThai, dvc.DiaChiGiaoHang FROM DiemGiaoHang dg INNER JOIN TuyenDuong td ON dg.IdTuyenDuong = td.Id INNER JOIN DonVanChuyen dvc ON dg.IdDonVanChuyen = dvc.Id WHERE CAST(td.NgayGiaoHang AS DATE) = @Today ORDER BY dg.ThuTuDung;
✨ Sau khi chạy SQL:
  • ✅ Tuyến đường hôm nay sẽ được tạo với mã TD-Q1-[ngày]
  • ✅ 4 điểm giao hàng sẽ được thêm vào
  • ✅ 2 điểm đã giao, 2 điểm chờ xử lý
  • ✅ Trang driver-routes.html sẽ hiển thị dữ liệu này
